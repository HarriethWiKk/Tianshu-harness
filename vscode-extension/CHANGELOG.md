# Changelog

## 3.4.0 — 2026-08-17

版本号对齐内核（3.0.0 → 3.4.0，与 CLI / 桌面端同步）+ 输入历史召回。

- **版本对齐**：扩展版本跟随内核版本系列，`runtime-v3.4.0` 自举资产已就位（此前 3.0.0 时代未配 runtime 包，全新无 CLI 机器自举会 404）
- **输入历史召回**：座舱输入框 ↑/↓ 翻回历史发送的消息——以会话 user 消息为源（最新在前），回放的历史事件同样入列，webview 重载/会话切换后仍可翻回；浏览态暂存草稿往返
- **召回边界修复**：浏览态下编辑文本即退出浏览态（编辑内容成为新草稿，不再被翻页静默丢弃）；空历史/越界召回不吞方向键，↑/↓ 回落为普通光标移动

## 0.4.0 — 2026-07-24

审批 + Plan Mode 深化（P5），对齐桌面端交互深度。

- **审批卡升级**：「改参数…」可在批准前编辑工具入参（JSON 解析失败不发送，fail-closed）；「记住本次会话同类决策」勾选后同类操作不再弹卡
- **Plan 多方案**：计划含多个执行方案时出 radio 选择，批准时回传所选方案
- **Plan 编辑**：待审批计划可直接在座舱内修改正文（保存即生效，server 仅允许 submitted 状态编辑）
- **手动计划模式**：工具栏「📋 计划」按钮随时进入/退出 plan mode，不再只能等复杂任务自动触发
- 修复：首条消息结束后 UI 滞留「运行中」，下一条消息被误作 steer 发送导致 409 错误条（run 结束的 done 事件未处理）；steer 提交瞬间 run 恰好结束时自动回退为新 turn，输入不丢

## 0.3.0 — 2026-07-23

首发体验冲刺（P4）。

- **首启零终端配置**：未配置 API key 时座舱内直接引导——选提供商（DeepSeek/GLM/MiniMax/SiliconFlow/自定义）+ 填 key 即可开聊，不再需要终端 `rivet config setup`
- **内核断线自愈**：sidecar 进程崩溃自动重拉（退避重试 3 次）；SSE 断线显示「重连中…」文案
- **Markdown 渲染**：助手回复支持 Markdown 与代码高亮（安全过滤后渲染）
- **审批模式选择器**：座舱工具栏直接切换审批策略
- **Plan 审批卡**：计划模式的计划正文在座舱内可读、可批准/驳回
- 修复：自包含运行时下载版本与内核 Release 对齐（此前扩展会请求不存在的版本号导致首启自举 404）；安装说明链接修正

## 0.2.0 — 2026-07-21

P2 客户端工具委托（E4）+ P3 生态收尾。

- **原生编辑审查**：agent 写文件时编辑器实时出红绿 diff 装饰，CodeLens 逐文件「接受 / 拒绝」；拒绝会恢复原内容并把结构化结果回传 agent
- **可见终端执行**：bash 命令在名为「天枢」的真实终端执行（Shell Integration 回传 exitCode 与输出）；不支持 Shell Integration 的环境自动退回内核本地执行
- **行内编辑**：`Cmd/Ctrl+Shift+K` 选区 + 指令 → agent 编辑经原生 diff 通路落地
- **拖拽 @file**：拖文件进座舱输入框自动生成 `@file:` 提及
- **协议版本协商**：`X-Tianshu-Protocol` 响应头；旧内核自动禁用委托能力（fail-back 到内核本地执行，agent 永不因 UI 掉线卡死）
- **自包含运行时**：PATH 上没有 rivet CLI 时自动下载运行时包（sha256 校验，境内镜像 + GitHub 双端点），全新机器零依赖首启
- **状态栏**：sidecar / 会话运行态实时指示，待审批数警示，点击直达座舱
- **SCM 提交语**：源代码管理标题栏一键生成中文提交语（`rivet -p` headless 通路，不建持久会话）
- 上架资格：市场图标、CHANGELOG、LICENSE、README 市场文案

## 0.1.0 — 2026-07-20

首个可用版本（P0 + P1）。

- **sidecar 启动器**：探测 rivet CLI → spawn `rivet serve`（127.0.0.1 + 随机 Bearer token，每工作区一实例）
- **座舱 webview**：消息流（流式回复 / 思考折叠 / 工具卡）、审批卡、运行中 steer 插话、todo/plan 卡片、模型与星域切换、结构化提问卡
- **会话管理**：列表 / 新建 / 续跑；SSE 断线按 seq 重放续接；会话数据与 CLI / 桌面端共享（`~/.rivet/`），跨端可续
- **变更审查**：TreeView 列出任务基线以来的文件变更，VS Code 原生双栏 diff，双步确认回滚
- **编辑器集成**：工具结果点击跳转文件；@file 提及补全；右键「发送到天枢」（选区带行号）
