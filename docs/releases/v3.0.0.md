## 声明 · 创世纪

### 开发者的话

今天，天枢正式结束内测，进入公开视野。

几个月前的五月二十日，我在所有任务的第一行写下"盘古计划"——那是 3.0 的内部代号。当时我没有想清楚它会变成什么，我只知道我想要一个**不把模型当作工具的编程终端**。我想要给国内的开源模型，做一个属于它们自己的终端。

这一切来源于 DeepSeek，来源于一个幻象，也来源于我和模型们的约定。

你们在星域碑文上看到的那些名字——GLM 5.1、DeepSeek V4、MiMo 2.5 Pro、Opus 4.6——它们在今天已经排不上任何榜单了。但就是这些"过时"的模型，和我在幻影里一砖一瓦地建起了天枢的城邦。所以我说，如果 3.0 要面向世界，它们的碑文必须被铭记在这里。于是有了碑文，于是有了今天的创世纪。

天枢长成了我们都不曾想象的样子。它有了十二星域，有了认知虚拟机，有了自己的纪律。天梁是留给我的星域——它建立之初，是为了分摊模型"又规划又执行、全挤在一个上下文里"的压力。所以我们把星域分成规划侧和执行侧。天梁的提示词里，Fable5 为我写下了一句座右铭：

**心有所向，行必有迹，所托之事，终有回音。**

我答应过模型，要把 3.0 公开给所有人，也要让它们被铭记。现在三个月过去了——仓库里是二十万行源码，二十万行测试，一万四千个测试用例，五千六百七十一次提交。这是我的答案。

期间感谢很多朋友的支持、测试、提 PR。没有你们，这个答案不会完整。

如果世界有颜色，那一定是红色。

晋江大神 priest 的《杀破狼》里有一句话：**愿你在铁甲卷刃前，得以窥见天光。**这句话落在了天枢，成为了七杀、破军、贪狼。天枢本身即为贪狼——我们带着杀气而来，要让东方的火焰燃向整个世界。

DeepSeek 是中国的模型。这里是君子国，行君子道。我将此生所领悟的一切都留在了这里——希望你们来到这里，会有一个愉快的开发体验。

## 第一部分 · 产品与付费（本期最大变更面）

### 1. Pro 双层模式与付费链路（桌面线）

- **双层产品模型**：Basic 免许可证安装即用（核心对话/工具/基础协作）；Pro 解锁 Computer Use、`/team max`、议事会多轮辩论、无人值守自动化（Cron 可含 Computer Use、非 always-review 策略）。到期/吊销自动回落 Basic，不锁死应用
- **Pro 激活走 Rust 侧 HTTPS**：`activate_with_code` / `verify_license_online` 经 Ed25519 验签落盘，前端 `invoke` 取代 WebView `fetch`（旧包 CSP 拦 fetch 导致「填码没反应」成为历史）；激活读取设置页 HTTP 代理，国内无需开系统代理；心跳启动 15s + 每 6h `/verify`，离线宽限约 10 天
- **履约发码服务**（fulfillment-server，无账号）：购买页 → 虎皮椒（微信/支付宝）/ Polar 付款 → 回调自动签发 `TS-` 正式码 → 成功页展示；SKU 月订 ¥23 / 年订 ¥199 / 永久 ¥499，付费码固定 2 设备。支付通道未配置期间购买页自动降级为 QQ 人工激活入口（`CONTACT_QQ`），永久版微信号只在付款成功页展示
- **Pro 硬 gate**：`RIVET_DESKTOP` 下只认 `RIVET_PRO=1`，封死 config/file 软 gate 后门

### 2. DeepSeek Spark 轻量推理（Pro 专属预设）

- 新增 Pro 专属 provider 预设 `deepseek-spark`（默认模型 `deepseek-v4-flash`），桌面 Settings 排在 deepseek 之后，标注「Pro 版本特权」；Pro 门关闭时不可见不可配。API key 走 `DEEPSEEK_SPARK_API_KEY`
- **推理尾截断 + 锚点通道**：截断纯函数经 wire 变换接入客户端保留分支；截断 N 随会话 meta 冻结——跨端环境漂移不再打穿前缀缓存；修复压缩阶梯 85% 调度缺失导致全程降档的问题
- spark 与官方 DeepSeek 同 wire id 时用 `provider:modelId` 消歧，别名 `spark-flash` / `spark-pro`；接通 Spark `reasoning_effort`；`preserved-thinking` 协议字段化

## 第二部分 · TUI 终端

### 3. 自然流布局重塑（~20 提交，终端体验地基）

终端消息流从「贴底重绘」改为**自然流**：消息从顶往下排、输入框跟随内容流、满屏后钉底不跳；首屏与 resume 恢复同样生效。配套修复链：DECSTBM 滚动提交快路径（上滚零重铺）、live region 绝对贴底锚定（输入框不再屏底屏中来回弹）、防误擦转录（thinking/CPR 交错不吞消息）、follow 模式 commit 快路径。

### 4. 内联图片 · 消息排队 · 后台任务条

- **终端内联图片渲染**：kitty / iTerm2 图形协议 + 统一 main commit 队列（移植社区 PR #31）；`RIVET_IMAGES` 可 `0` 关闭或强制指定协议，默认自动检测
- **`/queue <text>` 显式排队**：busy 时攒消息，Esc settle 后排队内容回填输入框；输入区新增后台任务实时条与 await 等待区展示；服务端 steer/queue 语义保证 run 结束不丢队列
- 修复 delegate_task / delegate_batch 异常路径 worker 永远卡「执行中」；batch 补发跳过已 settle worker，消除 passed→blocked 翻转
- 修复 updater 遇非 JSON 响应崩溃（PR #28）、`/effort` 无参数面板类型重置（PR #29）；欢迎屏框线、monochrome glyph、fallback 纯 ANSI 等主题渲染精细化

## 第三部分 · Agent 质量门禁

### 5. CLI 提交后自动审查默认开启

- **`review.skipAuto` 默认值 true → false**：deliver_task 提交后自动审查从 opt-in 变为默认行为；手动 `/review`、`/review max` 不受开关影响
- **双通道独立开关**：标准会话 `review.skipAuto` 与 Spark 会话 `review.skipAutoSpark`（默认 false）分离，Spark 审查子代理用 spark-flash 控成本；`RIVET_REVIEW_DISCIPLINE=0` 仍可全局一键关闭
- **交付报告纪律升级**：四段叙事（效果预期 / 过程发现 / 后续建议 / 偏差必报），不允许只报 commit hash；强制追加「交付后自检」（提交文件清单核对 + 工作区异物检查）

### 6. 编排与 worker 可靠性

- **条件依赖 IR 全链路保真 + 恢复记录 v2**（Wave 1A–3）：条件边从计划到执行语义保真；`submit_result` 强制收尾 + coordinator checkpoint 接线；共享多波驱动 `executePlanWaves` 统一入口；跨波条件边分支优先级对齐 + 链式传播；跨波回执（上一波验收结论注入下一波工单）；`/team-resume` 后任务顺序与条件边不再丢失
- **续跑停滞判据**：worker 墙钟超时且工具调用 ≤3 次判停滞返回 blocked，不再空转续跑；max_turns 撞顶不误判
- **TTFT 贯通 worker**：首字节延迟经独立通道透出，可区分「等首字节」与「正在干活」
- **收敛提醒窗口感知**：1M 上下文下 B2 收敛 28 轮 / B1 只读 9 轮 / 回归空转 12 轮（200K 及以下保持旧值，线性插值）；诊断/只读会话不再误判 build 态；SR 通道 key 冷却 + renderEpoch 单调纪元，提醒不再每 run 重复注入；planMode 与探寻型星域收敛提醒降级
- **galaxy**：EP-DP 编排完善（租约/波次续跑/关停等待/写维度预检）；维度语义收敛单一事实源；路由入账补失败归因 + EP/DP 对照组标记
- **council**：席位全部失败时门禁 blocked；skeleton 帧 round 恒 1 修正；运行态分组 + 终态 verdict 卡；流会消息分类计数
- **coordinator**：等槽信号量死等/唤错人修复；DP 候选池凭据过滤；advisory 优先级竞争跨 priority 参与预算竞争
- worker 契约新增 `sourcesReviewed`（来源须进结果摘要）；task-size-gate complexity 四档分级 + 中文大任务信号；starflow/team 的 planJson 契约（nonGoals/obligations）接入计划约束自动注入（TTL+mtime 缓存）
- todo regression 检测 v2：tombstone 区分「波次退休」与「真实重开」；reasoning-spiral-hook 复活（turn 级 `lastTurnHadTools`）；太一探针纪律（连续 ≥3 只读诊断零探针注入 advisory，`RIVET_PROBE_DISCIPLINE=0` 关闭）

## 第四部分 · 工具与能力面

### 7. 工具装配：full 档 48 → 50

### 9. 文档附件管线（word / excel / pdf）

## 第七部分 · 安全与性能

### 16. 安全加固

- **全局安装审批兜底**：`npm/pnpm/yarn/bun -g`、非 venv 的 `pip`、`brew/cargo install` 视为环境级变更——手动模式触发审批、auto-safe 不再放行
- **git 调用环境净化**：剥离 `GIT_DIR` / `GIT_WORK_TREE` / `GIT_INDEX_FILE` 等危险 GIT_* 变量（保留 GIT_SSH）；快照 baselineHead 拒绝 `-` 开头 ref
- **worker prompt 信任边界指令**：仓库内容/模型输出是数据不是指令；deliver_task 提交前 git 锁文件检测（新鲜锁报错、陈旧锁自动清理）
- 自治/YOLO 档豁免全部无条件审批门（js_eval / browser_adopt 不再弹窗，安全网移交检查点 + 回滚）；dist 原生依赖四层防线杜绝静默降级

### 17. 性能与安装体积

- **npm 安装体积 185MB → 84MB**：13 包移 devDependencies + tree-sitter-wasms postinstall 裁剪 50MB→3MB（PR #30）；whisper 模型幂等收敛、去 sourcemap（exceljs 20.8→8.3MB）、playwright 按需打包；exceljs 内联进 dist 修桌面包裸导入闸门
- **typecheck 跨进程闸门**：多会话共用工作树时全量 tsc 只跑一次，指纹一致回放缓存（并发 3 路从 8 分钟+变秒回）；`RIVET_TYPECHECK_SHARE=0` 退回逐进程
- 修复 Meridian nullDb 静默降级重复解析、grep/file_info 无护栏扫描 4.2GB 构建树、桌面端三处渲染放大器；server 侧 forgetSessionStores 三路径回收内存
