# guides/ — 手册指南

本目录存放**手册指南**：面向用户或开发者的操作型文档（怎么安装、怎么配置、怎么排查）。

与其他目录的区别：
- `reference/` — 是什么（架构描述、指标）；guide 是怎么做（步骤导向）
- `analysis/` — 针对单次问题的归因；guide 是长期有效的操作手册
- 历史遗留：docs 顶层的 `user-guide*.md`、`desktop-guide.md`、`WINDOWS-*.md` 等属此类，暂留原位，新指南放本目录

规范：语义命名无日期前缀，frontmatter `type: guide`。总纲见 [../README.md](../README.md)。
