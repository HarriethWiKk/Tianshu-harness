# specs/ — 事前规格

本目录存放**事前规格**：做什么/为什么——用户故事、编号需求（FR-XXX）、验收场景、成功标准（SC-XXX）。

与其他目录的区别：
- `design/` — 怎么做 + 权衡（spec 的下游）
- `plans/` — 执行追踪（spec 的下游）
- `known-issues/` — 已存在问题的追踪，不是新需求
- `superpowers/specs/` — 历史主仓（212 篇），保留不动；新规格放本目录

规范：命名 `YYYY-MM-DD-主题.md`，frontmatter `type: spec`，模板 `docs/_templates/_spec.md`。总纲见 [../README.md](../README.md)。
