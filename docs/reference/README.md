# reference/ — 参考资料

本目录存放**长期有效的参考资料**：架构描述、指标基线、能力地图——回答"是什么"。

与其他目录的区别：
- `guides/` — 怎么做（步骤导向）；reference 是什么（信息导向）
- `analysis/` — 针对单次事件；reference 持续有效、按需更新
- 历史遗留：`architecture-overview.md`、`engineering-metrics.md`、`codebase-index.md`（已过时，待重建）等顶层文件属此类，暂留原位，新参考放本目录

规范：语义命名无日期前缀，frontmatter `type: reference`。总纲见 [../README.md](../README.md)。
